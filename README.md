# VideoBatchCutter - 视频批量剪辑工具

基于 WinForms + FFmpeg 的视频批量分段剪辑工具，采用 TRAE 暗色设计风格。

## 功能

### v2.0（当前版本）
- 支持 8 种输出编码器：CPU H.264/H.265、NVIDIA NVENC、Intel QSV、AMD AMF
- 硬件编码失败自动回退到 CPU 编码器
- 处理前实时估算（总片段数、总时长、占用空间）
- 左侧设置面板竖直滚动条
- 视频列表状态与进度实时刷新
- 可去除视频前 5 秒
- 每视频最多 512 段
- TRAE 暗色沉浸式 UI 设计

### v1.0（基础功能）
- 按时长/段数自动分割视频
- 支持批量添加视频（拖拽/选择）
- 自动打包为 ZIP
- 输出路径/配置自动记忆
- 重复文件检测

## 使用方法
1. 下载并运行程序
2. 选择输出目录
3. 添加视频文件（拖拽或点击添加）
4. 设置分段参数与输出编码器
5. 查看估算信息确认参数
6. 点击"开始处理"

## 依赖
- FFmpeg（需添加到系统 PATH 或放在程序同目录）
- .NET 8.0 Runtime
